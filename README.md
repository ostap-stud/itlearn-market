# ITLearn Market Frontend

**Тема:** веб-платформа для продажу цифрових освітніх продуктів з персоналізованим підбором навчальної траєкторії.

Проєкт реалізує клієнтську частину навчальної e-commerce системи для продажу цифрових освітніх матеріалів у сфері ІТ. Основна відмінність від звичайного інтернет-магазину — модуль підбору індивідуальної навчальної траєкторії. Користувач задає навчальну ціль, рівень підготовки, бюджет і бажаний темп, а система пропонує послідовність продуктів, які можна додати до кошика як один навчальний набір.

## Основні можливості

- головна сторінка з позиціонуванням платформи;
- каталог цифрових продуктів з пошуком і фільтрами;
- сторінка детального перегляду продукту;
- підбір персоналізованої навчальної траєкторії;
- кошик і оформлення замовлення;
- вхід користувача та особистий кабінет із придбаними матеріалами;
- адміністративна панель для керування каталогом;
- сторінка аналітики продажів, популярних напрямів і подій взаємодії;
- підтримка GA4 Measurement ID через змінну середовища.

## Структура проєкту

```text
src/
  api/               # клієнт для REST API та локальне збереження даних
  components/        # повторно використовувані UI-компоненти
  data/              # початкові товари та тестові користувачі
  pages/             # сторінки застосунку
  utils/             # форматування, storage, аналітика
```

## Необхідне ПЗ

- Node.js 20 або новіша LTS-версія;
- VS Code;
- рекомендовані розширення VS Code: ESLint, Prettier, Tailwind CSS IntelliSense.

## Запуск локально

```bash
npm install
npm run dev
```

Після запуску Vite відкриє застосунок за локальною адресою, яку покаже в терміналі.

## Підключення до Spring Boot API

Для роботи разом із backend-проєктом потрібно запустити backend на адресі:

```text
http://localhost:8080/api
```

У корені frontend-проєкту можна створити файл `.env` на основі `.env.example`:

```env
VITE_API_BASE_URL=http://localhost:8080/api
VITE_API_MODE=auto
VITE_GA_MEASUREMENT_ID=
```

Режими роботи:

```text
VITE_API_MODE=auto   # пробує API, за відсутності API використовує локальні дані браузера
VITE_API_MODE=api    # працює лише з API
VITE_API_MODE=local  # працює з локальними даними браузера
```

## GA4

Щоб фіксувати події в Google Analytics 4, потрібно створити потік даних для вебсайту, отримати Measurement ID та додати його у змінну середовища:

```env
VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

У застосунку відправляються події перегляду сторінок, перегляду товару, додавання до кошика, початку оформлення, покупки, входу в систему та формування навчальної траєкторії.

## Підготовка production-збірки

```bash
npm run build
npm run preview
```

Папка `dist` містить готову статичну збірку, яку можна розмістити на GitHub Pages, Vercel або іншому хостингу для статичних сайтів.
